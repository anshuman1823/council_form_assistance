Council Form Aggregation and Accessibility

Problem Addressed:
- Over 1.6 million monthly users access the Council Website.
- 500,000+ users visit just three sub-domains (for social housing, school admissions, and council tax).
- These services are crucial, yet many users face accessibility barriers, especially disadvantaged groups.
- Issues addressed relate to UN Sustainable Development Goals (SDGs): Poverty, Health, Education.

Project Aim:
- Improve accessibility of essential services for:
  - People with disabilities
  - Elderly individuals
  - Non-technical users
  - Non-native English speakers
- Reduce workload on council phone support teams.

Workflow Overview:
1. User struggles to navigate the council site (which has over 27,000 pages; only 20% actively used).
2. A Conversational AI identifies the user's intent.
3. A vector index searches relevant government content.
4. The system returns the most appropriate pages.
5. Optionally, the system helps fill out the forms.

Key Takeaways:
- Access isn’t binary – delays cause users to abandon searches.
- Solutions should:
  - Be simple
  - Ensure services reach those in need
  - Be automatic to reduce friction
- Future improvements:
  - Fully integrate the web app
  - Add language translation support
